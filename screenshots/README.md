# Dashboard Screenshots

This directory is designated for high-resolution user interface captures of the Smart Food Storage Monitoring Dashboard.

## Recommended Screenshots

When preparing visual assets for documentation and repository showcase, capture the following views in light theme (`1280x800` or `1920x1080` resolution, PNG format):

1. **`01-overview.png`** — Overview Page showing chamber health status, environmental metric cards, and 24-hour historical trend charts.
2. **`02-live-monitoring.png`** — Live Monitoring Page displaying real-time gauge telemetry for temperature, humidity, and MQ135 analog ADC readings.
3. **`03-risk-analytics.png`** — Risk Analytics Page showing composite spoilage risk score, parameter contribution breakdown, and mathematical formula explanation.
4. **`04-equipment-status.png`** — Equipment Status and Automatic Operation Page detailing fan relay commands, vent servo positions, and buzzer alarm state.
5. **`05-alerts.png`** — Condition Alerts Page showing environmental thresholds, system condition logs, and historical alert table.
6. **`06-device-info.png`** — Device Information Page displaying ESP32 microcontroller architecture, Blynk Cloud connection status, and Virtual Pin datastream table.

## Note
Do not commit temporary testing screenshots or captures containing private Blynk tokens, Wi-Fi SSIDs, or network credentials.
